# 从零读懂 Pi 编程代理

本书面向尚未掌握 Node.js 和 TypeScript、希望理解并修改 Pi 源码的读者。学习目标是：能够从用户输入追踪到模型请求、工具调用、文件修改、会话保存和终端渲染，并说明每一步的状态、错误与并发边界。

教材按章节分别保存，每章一个独立文件。使用下面的目录逐章阅读或按主题查找。

可以直接在 GitHub 阅读本书。源码链接指向 Pi 的固定提交；教材新增或修改的示例与测试保存在 [labs/overlay](labs/overlay)。运行实验时，把教材与 Pi 源码放在同级目录。实验命令从教材目录运行，安装项目依赖的命令从 `pi` 仓库运行；首次准备步骤见 [实验说明](labs/README.md#首次准备源码)。

```text
WorkShop/
├── pi/                 # 源码仓库及其 node_modules
└── pi-source-book/     # 分章教材、附录与 labs
```

教材以提交 `11449730c8a733953ce1bcce70e066bccaa778a5` 为源码基准，最新核验日期为 2026 年 10 月 4 日。书中“当前实现”均指这一提交；本次测试修复、测试辅助改动和新增教学示例另记于附录 B 与哈希记录，实验性代码会单独注明。源代码定位使用仓库相对路径和函数名，行号仅作为这一版本的辅助定位。

每章采用同一种阅读顺序：先看要解决的问题，再看具体输入和执行轨迹，然后分析实现及其保证，最后用练习检查理解。代码中没有实现的机制，不会因为它在其他系统中常见而被写成 Pi 的已有能力。

## 源码与实验的区别

标记为“教学简化代码”的代码段只解释机制，不是直接复制的生产实现。标记为“根据实现可推导”的结论来自执行顺序或数据结构分析，不能理解为已经有对应测试覆盖。

本次修改教材和配套实验，修复测试中的 Cloudflare 模型标识，为会话 harness 增加可选 cwd，并新增字面搜索示例与会话测试；运行时源码保持基准内容。阅读已有测试与运行通过是两种证据；本次没有运行完整测试集、构建、发布或真实模型请求。run-offline.mjs 只依赖 Node 和当前源码；完整会话与 SQLite 恢复实验使用仓库依赖，执行命令和环境隔离见 labs。

已交付并运行 8 组、26 个离线用例，覆盖 transcript、预算、代理循环、压缩切点、BM25、规划、多代理与文件队列。初版的 14 组临时实验单列为历史记录，不声称已有可复现脚本。工程检查的结果与限制见附录 B。

另外交付完整集成实验入口，运行 7 个新增会话/扩展用例与 9 个既有 Durable SQLite 恢复用例，共 16 个命名用例。第 35 章包含固定输入、逐次请求、真实文件和日志断言、重建会话步骤，以及一个实际经历失败和修复的扩展开发案例。第 36 章逐章回答前 35 章的练习。

第 5—8、14、23、26、34 章加入生产源码节录与具体数据分析，第 35 章节录实际交付的示例和测试；[同步程序](labs/sync-book.mjs) 检查这些节录、分章目录、章节统计、链接和源码哈希。教材使用流程图、执行轨迹、保证矩阵和练习，将已有实现与可选增强分开。
